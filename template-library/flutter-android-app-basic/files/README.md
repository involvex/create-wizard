# Flutter Android App Basic Template

This template creates a basic Flutter Android application with the following features:

- Basic Flutter setup with Material Design
- A simple counter app (the default Flutter demo)
- Android and iOS project structure
- Basic pubspec.yaml configuration

## Getting Started

To create a new project using this template:

```bash
create-wizard my-flutter-app
```

Then select the `flutter-android-app-basic` template from the list.

## Project Structure

- `lib/main.dart` - Contains the main Flutter application code
- `android/` - Android-specific project files
- `ios/` - iOS-specific project files (for completeness)
- `test/` - Unit test directory
- `pubspec.yaml` - Flutter project configuration

## Features

- Uses Flutter stable channel
- Material Design implementation
- Basic state management with setState
- Responsive layout

## Next Steps

After generating your project, you can:

1. Run `flutter pub get` to install dependencies
2. Run `flutter run` to launch the app on a device or emulator
3. Modify `lib/main.dart` to customize your app
4. Add additional dependencies to `pubspec.yaml` as needed
